# AGENTS.md — skills-library

> Generated by `agents-md-gen` skill using Skills-First Development methodology.

## Project Overview

The **skills-library** is the primary product of Hackathon III. It contains 8 reusable AI skills that teach Claude Code and Goose how to build the LearnFlow cloud-native application autonomously.

**The Skills are the product** — not just documentation.

## Repository Purpose

- Provides reusable SKILL.md + scripts pairs for common cloud-native operations
- Works on Claude Code, Goose, and OpenAI Codex (no modification needed)
- Implements the MCP Code Execution Pattern: 80–98% token reduction

## How Skills Work

Each skill follows the **MCP Code Execution Pattern**:

```
SKILL.md (~100 tokens)  → Loaded by agent — tells it WHAT to do
scripts/*.py/.sh (0 tokens) → Executed, never loaded into context
Output (~15 tokens)     → "✓ Task complete" — only result enters context
```

**Token budget per skill**: ≤150 tokens (SKILL.md must be concise).

## Using Skills

```bash
# Claude Code
claude "Deploy Kafka using kafka-k8s-setup skill"

# Goose
goose "Deploy Kafka using kafka-k8s-setup skill"

# Both produce identical results
```

## Writing New Skills

1. Create directory: `.claude/skills/<skill-name>/`
2. Write `SKILL.md` with YAML frontmatter (≤150 tokens)
3. Create `scripts/` with executable scripts
4. Scripts output ≤30 tokens (just "✓ done" style messages)
5. Add `REFERENCE.md` for deep docs (loaded on-demand only)

See `docs/skill-development-guide.md` for full guide.

## Conventions

- All scripts: `set -euo pipefail` at top
- All scripts: Exit 0 on success, non-zero on failure
- All scripts: Print "✓ <action>" on success, "✗ <action>" on failure
- SKILL.md YAML frontmatter: `name`, `description`, `tools`, `allowed-tools`
- Scripts use env vars from `.env` (never hardcode secrets)
