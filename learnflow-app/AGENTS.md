## Service Architecture

Each FastAPI service follows this pattern:

```
main.py                          ← FastAPI app
requirements.txt                 ← Python dependencies
Dockerfile                       ← Container image
k8s/
  deployment.yaml                ← Dapr-annotated deployment
  service.yaml                   ← ClusterIP service
dapr/
  subscription.yaml              ← Kafka topic subscription
```
