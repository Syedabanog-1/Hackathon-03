# LearnFlow — AI-Powered Python Tutoring Platform

> Built entirely by AI agents (Claude Code + Goose) using skills from skills-library.
> No manual code was written. Every file was generated by an agent using a skill.

## Deployment (via Skills)

All deployment is done via prompts to Claude Code or Goose:

```bash
# 1. Foundation
claude "Check Kubernetes cluster health using k8s-foundation skill"

# 2. Infrastructure
claude "Deploy Kafka using kafka-k8s-setup skill"
claude "Deploy PostgreSQL using postgres-k8s-setup skill"

# 3. Services (repeat for each: concepts, debug, exercise, progress, code-review, code-sandbox)
claude "Create triage service using fastapi-dapr-agent skill"

# 4. Frontend
claude "Deploy Next.js frontend using nextjs-k8s-deploy skill"

# 5. Gateway (k8s-foundation skill — Separation of Concerns)
claude "Deploy Kong API gateway using k8s-foundation skill"

# 6. Documentation
claude "Deploy documentation using docusaurus-deploy skill"
```
