## Deployment Order (via Skills)

1. `k8s-foundation` — verify cluster, create namespaces
2. `kafka-k8s-setup` — deploy Kafka, create 5 topics
3. `postgres-k8s-setup` — deploy PostgreSQL, run migrations
4. `fastapi-dapr-agent` × 7 — scaffold + deploy all services
5. `mcp-code-execution` — deploy Kong + configure routes
6. `nextjs-k8s-deploy` — scaffold + deploy frontend
7. `docusaurus-deploy` — scaffold + deploy documentation

## LearnFlow Data Model

```sql
-- Users
CREATE TABLE users (id UUID PRIMARY KEY, name TEXT, email TEXT UNIQUE, role TEXT);

-- Modules (8 Python curriculum modules)
CREATE TABLE modules (id INT PRIMARY KEY, name TEXT, topics JSONB);

-- Progress tracking
CREATE TABLE progress (
  id UUID PRIMARY KEY, student_id UUID, topic_id TEXT,
  mastery_score FLOAT, exercise_count INT, quiz_scores JSONB,
  streak_days INT, updated_at TIMESTAMPTZ
);

-- Struggle alerts
CREATE TABLE struggle_alerts (
  id UUID PRIMARY KEY, student_id UUID, topic_id TEXT,
  trigger_type TEXT, created_at TIMESTAMPTZ, resolved BOOL
);

-- Exercises
CREATE TABLE exercises (
  id UUID PRIMARY KEY, topic_id TEXT, difficulty TEXT,
  prompt TEXT, test_cases JSONB, solution TEXT
);
```
