## Architecture Decisions

### Multi-stage Docker Build

Stage 1 (builder): `node:20-alpine` — `npm ci && npm run build`
Stage 2 (runner): `node:20-alpine` — copies `.next/standalone`
This keeps the final image small (~150MB vs ~500MB).

### Monaco Editor Integration

`@monaco-editor/react` loaded with `defaultLanguage="python"`.
Code execution: POST to `/api/v1/execute` → Kong → code sandbox service.
