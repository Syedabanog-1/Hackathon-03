## Agent Architecture

### Triage Agent (triage-service)

Subscribes to `student-events`. Inspects `intent` field:
- "explain" → publishes to `tutor-requests` with target=concepts
- "error" → publishes to `tutor-requests` with target=debug
- "exercise" → publishes to `tutor-requests` with target=exercise
- "review" → publishes to `tutor-requests` with target=code-review
- "progress" → publishes to `tutor-requests` with target=progress

### Specialist Agents

Each subscribes to `tutor-requests` filtered by their `target` field.
Processes request, writes response to `tutor-responses` topic.

### Dapr Components

- PubSub component: `kafka-pubsub` (type: pubsub.kafka)
- State store: `learnflow-state` (type: state.postgresql)
